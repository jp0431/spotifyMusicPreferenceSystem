# 🎧 Music Preference Intelligence System
Utilizando como base mi proyecto anterior, un dasboard de mi escucha en Spotify, He creado un sistema inteligente de preferencia músical.
# 🚀 Demo
https://spotifymusicpreferencesystem-dgxidexcyvnirklerfduam.streamlit.app
# 📊 ¿Qué muestra?
El proyecto esta divido en 3 paginas, 1 Dashboard, 2 Analisis de los grupos de musica y 3 sistema de predicción de Skips.
## Dashboard
🎧 Horas totales de escucha

🎵 Canciones reproducidas

🎤 Número de artistas distintos

⏭️ Porcentaje de canciones saltadas

🕒 Heatmap de actividad (día vs hora)

🎤 Top artistas

🎶 Top canciones

🧠 Perfil musical basado en comportamiento

# 🎛️ Funcionalidades

Filtro por mes

# ⚙️ Cómo ejecutarlo
git clone https://github.com/jp0431/spotifyMusicPreferenceSystem

cd spotifyMusicPreferenceSystem

pip install -r requirements.txt

streamlit run app.py

# 📂 Datos

Los datos provienen del historial de escucha de Spotify (Streaming History).
